# Профиль проекта — NL recreatiepark

> **Канонический источник** всех параметров проекта.

## Локация и статус

| Параметр | Значение |
|----------|----------|
| Страна / климат | **Нидерланды**, побережье (влажно, ветрено) |
| Участок | **Recreatiepark**, место **есть** |
| Коммуникации | **Электричество, вода, канализация** на участке |
| Разрешение | **Есть** (договор с парком) |
| Лимит | **50 m²** |
| Сваи / DIY | **Можно** |

## Этап 1 — сезон 2026

| Параметр | Значение |
|----------|----------|
| Коробка | **2 × 4 m** = **8 m²** |
| Сваи | **4–6** только под starter |
| Каркас | **45×95 mm** C24 |
| Высота стен | **~2,4–2,7 m** |
| Крыша | **Односкат** только над 2×4 |
| Назначение | **Сезонный**; зимой пусто (парк закрыт) |
| Внутри | **Санузел + мини-кухня**; спать тесно |
| Инженерка | Электричество, вода, канализация, душ |
| Стройка | **Сам + помощники**; опыта **нет** |
| Бюджет | Не определён (ориентир **€8–15k**) |

## Этап 2

| Параметр | Значение |
|----------|----------|
| Финал | **L**, **≤50 m²** |
| Геометрия | Starter = вертикаль L; **«ножка»** внизу буквы |
| «Ножка» | ~**42 m²** |
| Фундамент | Новые сваи + **связка** с starter |
| Крыша | **Расширение** односката |

→ [[milestones/M15-phase2-l-extension|M15]]

## Зима (пустой дом)
