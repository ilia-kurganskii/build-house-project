# M15 — Этап 2: «ножка» L (~42 m²)

← [[02-project-profile]] · Этап 1 готов (M10+)

**Цель:** **L** до **50 m²**; starter остаётся комнатой в вертикали буквы.

```
  ┌──┐
  │  │  ← этап 1 (2×4 m)
  │  │
  └──┬──┐
     │  │  ← этап 2 (~42 m²)
     └──┘
```

## Работы

1. **Сваи** под «ножку» + **жёсткая связка** с обвязкой [[milestones/M1-pile-strapping-floor-box|M1]]
2. Пол, стены **45×95**, OSB — как M1–M5
3. **Стык L** — двойные стойки, OSB на угол
4. **Удлинение односката** [[milestones/M7-rafter-system|M7]] → [[milestones/M10-roofing-ridge|M10]]
5. Утепление, WRB, инженерка спальни/гостиной
6. Отделка — [[milestones/M13-drywall-plancken|M13]]

## Критерии

- [ ] Σ площадей ≤ **50 m²**
- [ ] Стык starter ↔ «ножка» без трещин > 3 mm после сезона
- [ ] Кровля на стыке без протечек
- [ ] Пассивная вентиляция на всём объёме
