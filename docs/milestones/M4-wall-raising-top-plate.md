# M4 — Подъём стен (~2,5 m)

← [[milestones/M3-wall-framing|M3]] · → [[milestones/M5-wall-sheathing-bridging|M5]]

**Цель:** стены вертикально, верхняя обвязка, временные укосины.

## Работы

1. **Подъём** — **2 человека** достаточно при ~2,5 m; лучше **2–3**
2. **Укосины** (1 шуруп) → снять после [[milestones/M5-wall-sheathing-bridging|OSB]]
3. **Верхняя обвязка** — доски заходят на соседнюю стену
4. **Саморезы → гвозди**
5. Сторона под будущую «ножку» L — оставить **чистый стык** под M15

## Критерии

- [ ] Отклонение от вертикали ≤ 3 mm/m
- [ ] Проёмы совпадают с планом
