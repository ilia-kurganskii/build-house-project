# M12 — Wet-room (~2 m²) в starter

← [[milestones/M4-wall-raising-top-plate|M4]] · → [[milestones/M14-mep-finishes|M14]]

**Цель:** перегородка **душ + унитаз** в углу **8 m²**; остальное — кухня/сон.

## Планировка

```
2 m
┌─────────┐
│ wet ~2m²│
├─────────┤
│ kitchen │
│ + sleep │
└─────────┘
    4 m
```

## Работы

1. Перегородка **45×95 mm** + OSB или влагостойкий слой
2. **Наклон пола** в wet-room к трапу (мин. 1–2 cm/m)
3. Проём под дверь wet-room
4. **Вентканал** в wet-room (обязательно NL)

## Критерии

- [ ] Wet-room отделена от «сухой» зоны
- [ ] Трап/слив совместим с канализацией парка
