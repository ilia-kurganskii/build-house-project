# M1 — Сваи и обвязка starter 2×4 m

← [[milestones/M0-pre-construction|M0]] · [[02-project-profile]] · → [[milestones/M2-floor-system|M2]]

**Цель:** **4–6 винтовых свай** под **2×4 m**, обвязка, коробка пола.

## Работы

1. **4–6 винтовых свай** (углы + середина длинных сторон)
2. **Обвязка** 45×95 mm — диagonали **±5 mm**
3. **Обрешётка пола** (держит утеплитель, не несущая)
4. Сетка от грызунов
5. **Ветрозащита** на коробке (NL побережье)
6. **Коробка лаг** внутри 2×4 m; снова диagonали

## Критерии

- [ ] Площадь обвязки **2×4 m** ±10 mm
- [ ] Диagonали равны ±5 mm
- [ ] Задел под связку с «ножкой» L — [[milestones/M15-phase2-l-extension|M15]]
