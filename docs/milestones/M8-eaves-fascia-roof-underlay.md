# M8 — Карниз, лобовая, мембраны

← [[milestones/M7-rafter-system|M7]] · → [[milestones/M9-roof-insulation-batten|M9]]

**Цель:** лобовая односката, паро- и гидрозащита кровельного пирога (NL влажность).

## Работы

1. **Обрезка стропил** по линии карниза (шнур + уровень)
2. **Лобовая доска**
3. **Пароизоляция** с тёплой стороны (согласовать с [[milestones/M2-floor-system|M2]])
4. Подкровельная **дышащая мембрана** с нахлёстами и скотчем

## Критерии

- [ ] Линия карниза ±5 mm от шнура
- [ ] Мембрана непрерывна, проколы заклеены
