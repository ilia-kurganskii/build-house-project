# M9 — Утепление крыши и обрешётка

← [[milestones/M8-eaves-fascia-roof-underlay|M8]] · → [[milestones/M10-roofing-ridge|M10]]

**Цель:** минvata между стропилами, вентзазор, обрешётка под кровлю **8 m²**.

## Работы

1. **Минвата** между стропилами — респиратор; без бугра
2. **Контробрешётка** 25×50 mm — **не красить** (вентканал)
3. **Обрешётка** под выбранную кровлю ([[milestones/M10-roofing-ridge|M10]])
4. **У фронтонов** — сплошная обрешётка

## Критерии

- [ ] Вентканал 40–50 mm от карниза до верха ската
- [ ] Шаг обрешётки по инструкции кровли
