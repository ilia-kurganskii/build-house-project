# M0 — Подготовка (этап 1, сезон 2026)

← [[02-project-profile]] · → [[milestones/M1-pile-strapping-floor-box|M1]]

**Цель:** готовность к стройке starter **2×4 m** в recreatiepark NL.

## Чеклист

- [ ] Схема **2×4 m** на участке; «ножка» L внизу буквы — [[02-project-profile]]
- [ ] План **8 m²**: wet-room ~2 m² + мини-кухня + проход
- [ ] Смета NL (ориентир €8–15k)
- [ ] Заказ: **45×95 mm** C24, OSB 18, фанера 18, минвата, **4–6 винтовых свай**
- [ ] Кровля односкат: металл или EPDM — [[milestones/M10-roofing-ridge|M10]]
- [ ] Точки **электричества, воды, канализации** отмечены на участке
- [ ] Пассивная вентиляция зимой заложена в чертёж
- [ ] Высота односката — по правилам парка / Bouwbesluit
- [ ] **2–3 помощника** на подъём стен и кровлю

## Критерии

- [ ] Starter размечен ±20 mm
- [ ] Проёмы окна + дверь wet-room зафиксированы
- [ ] Материалы на участке до свай
