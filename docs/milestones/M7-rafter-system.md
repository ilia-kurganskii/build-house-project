# M7 — Односкат над 2×4 m

← [[milestones/M5-wall-sheathing-bridging|M5]] · → [[milestones/M8-eaves-fascia-roof-underlay|M8]]

**Цель:** стропила **односката** только на **8 m²**; задел под расширение — [[milestones/M15-phase2-l-extension|M15]].

## Работы

1. **Стропила** 45×95 или 45×145 mm
2. **Уклон** 5–15° — вода на сторону **водостока**
3. **Свес** карниза 30–40 cm
4. Шаг под утеплитель крыши (ширина − 10 mm)
5. На **низкой** стороне — отметка линии будущего **удлинения** кровли

## Критерии

- [ ] Крыша только над 2×4 m
- [ ] Конец стропил с низкой стороны — доступен для M15
