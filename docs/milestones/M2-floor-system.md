# M2 — Пол starter (8 m²)

← [[milestones/M1-pile-strapping-floor-box|M1]] · → [[milestones/M3-wall-framing|M3]]

**Цель:** лаги, утепление, пароизоляция, **фанера 18 mm** на **2×4 m**.

## Работы

1. **Лаги** на обвязку (макс. длина ~4 m — стыки не критичны)
2. **Бриджи** между лагами (*лага → бридж → лага*)
3. **Минвата** — плотно, без бугра
4. **Пароизоляция** с тёплой стороны
5. **Фанера 18 mm** — края на лагах; **промазка швов** (дождь NL)

## Размеры

| Правило | Значение |
|---------|----------|
| Шаг лаг | Ширина утеплителя − **10 mm** |
| Фанера | Края листа на лагах |

## Критерии

- [ ] Шаг = ширина утеплителя − 10 mm
- [ ] Пароизоляция непрерывна
- [ ] Швы фанеры промазаны
