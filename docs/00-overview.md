# Каркасный дом — обзор

> Профиль: [[02-project-profile]] · Граф: [[_graph]] · Агент: [[AGENT]]

## Два этапа

| | Этап 1 (сезон 2026) | Этап 2 |
|---|---------------------|--------|
| Площадь | **2×4 m** = 8 m² | **L** до **50 m²** |
| Фундамент | Сваи под starter | Сваи «ножки» + связка |
| Крыша | Односкат над 2×4 | Расширение односката |
| Внутри | Wet-room + мини-кухня | Спальня, гостиная |

## Материалы (NL)

- Каркас: **45×95 mm** C24
- Пол / стены: фанера и OSB **18 mm**
- Крыша: стропила + мембрана + односкат (металл или EPDM)
- Утеплитель: минвата (толщина — Bouwbesluit, уточнить в M0)
