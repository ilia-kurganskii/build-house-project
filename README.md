# Каркасный дом — документация проекта

Документация стройки каркасного дома в recreatiepark (NL): этапы, материалы, решения и зависимости между ними. Репозиторий рассчитан на совместную работу человека и AI-агента — Cursor, Claude Code, Windsurf и других.

## Быстрый старт

1. Клонируйте репозиторий и откройте папку как проект в IDE (Cursor, VS Code и т.п.).
2. Для навигации по связям между документами откройте корень репозитория как **Obsidian vault**.
3. Перед первым запросом агенту дайте контекст: «прочитай `AGENT.md` и `docs/02-project-profile.md`».
4. Язык документации и общения с агентом — **русский**.

## Структура репозитория

```
build-house-project/
├── README.md                 ← вы здесь
├── AGENT.md                  ← инструкции для AI-агента (читать первым)
├── .agents/skills/           ← навыки агента (skills)
│   └── grilling/             ← stress-test решений («grill me»)
└── docs/
    ├── 02-project-profile.md ← КАНОН: все параметры проекта
    ├── 00-overview.md        ← обзор этапов и материалов
    ├── _graph.md             ← граф зависимостей между документами
    └── milestones/           ← M0–M15: этапы стройки
```

**Канонический источник** — `docs/02-project-profile.md`. Если что-то противоречит профилю, править нужно профиль, а не отдельный milestone.

## Работа с AI-агентом

### Точка входа — `AGENT.md`

Файл `AGENT.md` в корне описывает, как агент должен работать с документами:

- проверять согласованность с профилем проекта;
- обновлять frontmatter (`when_changed_review`, `concepts`);
- синхронизировать связанные файлы по таблице триггеров в `AGENT.md`.

**Cursor** подхватывает `AGENT.md` автоматически при открытии проекта.

**Claude Code** — укажите в начале сессии:

```
Прочитай AGENT.md и docs/02-project-profile.md. Дальше работай по протоколу из AGENT.md.
```

**Другие агенты** — добавьте `AGENT.md` в system prompt, правила проекта или первое сообщение чата.

### Типичные запросы

| Задача | Пример запроса |
|--------|----------------|
| Обзор проекта | «Прочитай overview и profile. Кратко: что строим и на каком этапе?» |
| Детали этапа | «Открой M3 и проверь, нет ли противоречий с profile» |
| Изменение параметра | «Меняем толщину утеплителя — обнови profile и все связанные milestones по AGENT.md» |
| Новое решение | «Grill me: как лучше сделать вентиляцию зимой?» (см. skill `grilling`) |
| Проверка согласованности | «Пройди по _graph.md и найди расхождения между milestones» |

### Протокол правок

При любом изменении документа агент должен:

1. Сверить с `docs/02-project-profile.md` — нет ли противоречий.
2. Обновить frontmatter затронутого файла.
3. Проверить файлы из `when_changed_review` и таблицы триггеров в `AGENT.md`.
4. При смене концепта (`starter 2×4`, `односкат`, `L / 50 m²` и т.д.) — обновить все места, где он используется.

## Навыки агента (`.agents/skills/`)

Навыки — готовые сценарии работы агента. Лежат в `.agents/skills/<имя>/SKILL.md`.

| Навык | Когда использовать |
|-------|-------------------|
| `grilling` | Stress-test плана или решения: «grill me», «прогони через grill», «проверь решение» |

Агент задаёт вопросы раундами, сам ищет факты в репозитории и не действует, пока вы не подтвердите общее понимание.

**Cursor** — навыки из `.agents/skills/` доступны в Agent mode.

**Claude Code** — в начале сессии:

```
Прочитай .agents/skills/grilling/SKILL.md и применяй, когда я прошу «grill me».
```

## Obsidian

Vault = **корень репозитория**. Wiki-ссылки (`[[02-project-profile]]`, `[[milestones/M3-wall-framing]]`) работают между файлами.

Рекомендуемый порядок чтения:

1. `docs/02-project-profile.md`
2. `docs/00-overview.md`
3. `docs/_graph.md`
4. Нужный milestone из `docs/milestones/`

## Этапы стройки (кратко)

| 1 — сезон 2026 | M0–M14 | Starter **2×4 m** (8 m²): сваи → каркас → крыша → MEP → отделка |

Полная цепочка и зависимости — в `docs/_graph.md`.

## Советы

- **Один источник правды** — параметры проекта только в `02-project-profile.md`.
- **Конкретные запросы** — «обнови M4 под новую высоту стены 2,4 m и синхронизируй profile» лучше, чем «поправь документы».
- **Grill перед крупным решением** — перед изменением профиля или нескольких milestones прогоните решение через skill `grilling`.
- **Коммиты** — агент не коммитит без явной просьбы; попросите «закоммить изменения», когда документы согласованы.
